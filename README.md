#  🧠 Quiz sobre programação


### 🎯 Objetivo do projeto
O quiz foi desenvolvido com o objetivo de aprender e colocar em prática, de forma simples e interativa, os fundamentos básicos de programação em Python.

### 🤖 Tecnologias utilizadas
- Python
- Estruturas condicionais
- Variáveis
- Operadores de comparação
- F-strings

### 📝 Aprendizado
O desenvolvimento do quiz permitiu mais prática e aprendizado sobre python e seus conceitos, permitindo também a compreensão sobre como desenvolver uma lógica para a verificação das respostas e calcular a pontuação final, baseada em erros e acertos do usuário.
